# 📦 Installation

## Clone Repository

```bash
git clone https://github.com/devkhurana/AI-Resume-Analyzer.git
```

---

## Open Folder

```bash
cd AI-Resume-Analyzer
```

---

## Create Virtual Environment

```bash
python -m venv venv
```

---

## Activate Environment

### Windows

```bash
venv\Scripts\activate
```

---

## Install Packages

```bash
pip install streamlit pdfplumber pandas matplotlib pillow
```

---

# ▶️ Run Project

```bash
streamlit run app.py
```
